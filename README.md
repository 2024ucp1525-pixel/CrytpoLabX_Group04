# CryptoLabX

## Overview

CryptoLabX is a modular cryptography and cryptanalysis toolkit developed as part of the Cryptanalysis course. The project is designed to grow throughout the semester, beginning with a professional software structure and gradually incorporating classical ciphers, modern cryptographic algorithms, attack techniques, and analytical tools.

## Project Structure

```
CryptoLabX/
│
├── classical/      # Classical cipher implementations
├── attacks/        # Cryptanalysis and attack modules
├── math/           # Mathematical utilities
├── modern/         # Modern cryptographic algorithms
├── analysis/       # File analysis tools
├── datasets/       # Sample text files
├── outputs/        # Generated outputs and logs
├── docs/           # Documentation
├── tests/          # Unit tests
├── utils/          # Helper functions
│
├── main.py         # Main application
├── README.md
└── requirements.txt
```
